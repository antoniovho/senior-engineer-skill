# User Story Template

```markdown
---
name: "🧩 User Story SPEC"
about: "Detailed specification for a User Story."
title: "<insert_title_here>"
assignees: ""
labels: kind/story
type: "User Story"
---
## 📖 User Story

**As a** [type of user / persona name]
**I want to** [perform an action or achieve something]
**So that** [I get this benefit or outcome].

## 📝 Summary

A short summary of what this story is about, in 2-3 sentences. Focus on the user value.

## 🎯 Why This Matters

### User Value
What problem does this solve for the user? How does their experience improve?

## ✅ Acceptance Criteria

Write criteria that a non-technical person can verify. Each criterion should be testable by observing the product behavior.

- [ ] [When X happens, the user sees Y]
- [ ] [Given condition A, the user can do B]
- [ ] [The user receives confirmation when Z is complete]

## 🚫 Out of Scope

Clarify what is explicitly **not included** in this story. This prevents scope creep and sets clear expectations.

- [What we are NOT doing]
- [What is deferred to a future story]

## 📝 Additional Context

Any additional context, screenshots, user research quotes, competitor references, or notes that help understand the story.
```
